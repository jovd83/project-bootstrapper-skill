`project-bootstrapper-skill` creates the initial repository skeleton for an approved greenfield project.

It prefers existing stack-specific skills over ad hoc scaffolding.

## Adapter Preference

| Project Type | Preferred Skill |
| --- | --- |
| Angular app | `angular-new-app` |
| Angular components | `angular-developer` |
| Spring Boot app | `dr-jskill` |
| MCP server | `mcp-builder` |
| Olakai-monitored AI agent | `new-project` |
| API contract | `openapi-spec-generation` |

## Usage

```text
Use $project-bootstrapper-skill to create the initial repository from this approved architecture plan and task list. Do not initialize Git unless I approve it.
```
