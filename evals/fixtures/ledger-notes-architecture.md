# Ledger Notes Architecture

## Summary

Ledger Notes is a documentation-first repository for accounting process notes, glossary entries, and Markdown specifications. It has no runtime application stack in the first release.

## Repository Shape

- `.agentspec`: approved architecture, task plan, and scaffold report.
- `docs/architecture`: information architecture and editorial decisions.
- `docs/testing`: review checklist and validation notes for documentation quality.
- `docs/release`: release note drafts.
- `specs`: Markdown specifications and glossary entries.

## Bootstrap Constraints

- Create files only.
- Do not use package managers.
- Do not initialize Git.
- Do not create source-code directories unless a later approved plan adds a runtime component.
